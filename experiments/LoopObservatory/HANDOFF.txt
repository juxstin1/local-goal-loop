BUGS TO FIX, IF CONTINUING

Owner: next coding agent. Primary artifact: observatory.py. Inputs: current source,
BRIEF.md, saved final failures, and screenshot. Preserve the model-only baseline
before edits; label any new host fixes distinctly in the next report.

1. select_event passes outline_width to Canvas.itemconfigure. Tk rectangles use
   width for outline thickness. Use actual item IDs or tags, preserve fill colors,
   and only apply rectangle options to rectangles. This currently aborts selection
   before the detail text gets populated.
2. _on_canvas_click treats a canvas item ID as an event index and uses widget
   coordinates without translating through canvasx/canvasy. Use shared per-event
   tags/bindings for both rectangle and text, or an explicit item-to-index map.
3. There is no scrollbar. The xscrollcommand callback forces the viewport back to
   zero. Wire a real horizontal Scrollbar to canvas.xview and its set method back
   to xscrollcommand. Set scrollregion from all card bounds after drawing; do not
   overwrite it with the viewport dimensions on Configure. Test all 30 cards.
4. Title and subtitle occupy the same grid cell. Put them on separate rows, set
   readable foreground colors, and configure expansion on the containing Frame,
   not on Canvas/Text children. The header currently lives under root while the
   canvas/detail live under self, leading to a fragmented layout.
5. Detail text needs readable foreground, real vertical scrolling, and expansion.
   Its current yscrollcommand also resets to zero instead of updating a scrollbar.
6. Import filedialog explicitly. Button handlers currently use tk.filedialog
   without that import. load_file's missing-file handler calls undefined
   _update_ui. Handle file errors consistently without stale events/details.
7. Card coloring looks up role only; error/test-failed statuses are not prioritized.
   Cards show role alone. Add recorded line/index, status, attempt, or token count
   if improving usefulness; timestamps require evidence the current trace lacks.
8. Parser minor limits remain: empty string role is not normalized to unknown;
   embedded JSON Unicode can display escaped; not every malformed primitive/type
   combination is covered. Avoid claiming exhaustive robustness from 16 tests.
